# 🚀 EasyZip (초고속 압축 & 알집 지원 자체 탐색기 프로그램)

**EasyZip**은 대용량 파일 및 다국어 압축 파일을 가장 빠른 속도로 해제/압축할 수 있도록 설계된 차세대 Windows 전용 아카이브 매니저입니다.

---

## 🌟 주요 기능 및 지원 포맷

### 1. 🇰🇷 알집 전용 포맷 완벽 지원
- **ALZ 아카이브 (`.alz`)**:
  - 알집의 독점 고유 포맷인 ALZ 바이너리 헤더 파서 및 Deflate/BZip2 디코더를 자체 내장하여 외부 프로그램 없이 초고속 압축 해제 지원.
- **EGG 아카이브 (`.egg`)**:
  - 알집 최신 포맷인 EGG 아카이브 엔진 탑재로 완벽한 파일 목록 조회, 전체 압축 해제, 파일 단위 즉시 실행 지원.

### 2. 🌐 언어별 파일명 깨짐 및 해제 실패 원천 차단 (다국어 완벽 검토)
- **.NET 코드페이지 공급자 완벽 등록**:
  - 기본적으로 비활성화된 한국어(`CP949`/`EUC-KR`), 일본어(`Shift-JIS`/`CP932`), 중국어(`GBK`/`GB2312`/`GB18030`), 서유럽(`Windows-1252`) 코드페이지를 시스템 초기화 시 강제 등록.
- **지능형 다국어 인코딩 자동 감지 (Smart Encoding Detector)**:
  - 바이트 시퀀스의 UTF-8 유효성을 검사하고, 비표준 ANSI/CP949/Shift-JIS 압축 파일의 파일명을 자동으로 식별하여 글자 깨짐 방지.
- **안전한 파일명 정제 (Sanitization) & 긴 경로 (Long Path) 대응**:
  - 파일명에 포함된 불법 제어문자 및 Windows 금지 문자(`:`, `*`, `?`, `"`, `<`, `>`, `|`)를 안전하게 치환.
  - 상위 디렉터리 탈출 공격(Zip Slip) 원천 차단.
  - 언어 깨짐으로 인한 `DirectoryNotFoundException` / `PathTooLongException` 완전 방지.

### 3. ⚡ 초고속 멀티스레드 압축 & 해제 엔진
- **멀티스레드 병렬 추출**: CPU 멀티코어와 NVMe/SSD 대역폭을 최대로 가동하여 파일 단위 동시 병렬 디스크 쓰기.
- **1MB 대용량 I/O 버퍼링**: 디스크 I/O 시스템 호출 오버헤드를 90% 이상 감축.
- **지원 포맷**:
  - `ALZ`, `EGG`, `ZIP`, `7Z`, `RAR` (RAR4/RAR5), `TAR`, `GZ`, `TGZ`, `BZ2`, `TBZ2`, `XZ`, `TXZ`, `ISO`, `CAB`, `ZST`, `LZ`, `LZH`
- **실시간 통계 모달**: 처리 속도(`MB/s`), 예상 남은 시간, 실시간 게이지 제공.

### 4. 🗂️ 자체 내장 탐색기 (Dual-Mode)
- **로컬 디스크 파일 탐색기**:
  - 즐겨찾기(바탕화면, 다운로드 등) 및 로컬 드라이브(C:, D:) 목록
  - **새 폴더 생성**: 상단 툴바 및 우클릭 메뉴에서 언제든지 원클릭으로 새 폴더 생성
  - 압축 파일 더블클릭 시 즉시 압축 파일 탐색 모드로 전환
- **압축 파일 내부 탐색기**:
  - 폴더 계층 구조 트리 및 리스트 뷰
  - 내부 파일 더블클릭 시 임시 폴더에 고속 추출 후 기본 앱으로 바로 실행
  - 원본 크기, 압축 크기, 압축률, 수정일, CRC32 체크섬 표시
  - 드래그 앤 드롭 지원

### 5. 🖱️ 윈도우 탐색기 마우스 우클릭 메뉴 완벽 통합
- **압축 파일 우클릭 시**:
  - ⚡ `EasyZip: 여기에 압축 풀기` (`-x`)
  - 📁 `EasyZip: 각각의 폴더에 압축 풀기` (`-xd`)
  - 📂 `EasyZip으로 열기`
- **일반 파일/폴더 우클릭 시**:
  - 🗜️ `EasyZip으로 압축하기...` (`-c`)
  - 📦 `EasyZip: zip으로 빠른 압축` (`-cz`)
- **디렉터리 빈 공간/바탕화면 우클릭 시**:
  - 📁 **`EasyZip: 새 폴더 만들기`** (`-newfolder`)
  - 📂 **`EasyZip 탐색기로 열기`**

### 6. 📦 원클릭 전용 설치 프로그램 제공
- **독립형 설치 파일**: `d:\coding\visualstudio\easyzip\Setup\EasyZipSetup.exe` (약 1.9MB)
- 더블클릭 한 번으로:
  - 바탕 화면 바로가기 생성
  - 시작 메뉴 프로그램 폴더 등록
  - 윈도우 탐색기 우클릭 메뉴 자동 구성
  - `.alz`, `.egg`, `.zip`, `.7z` 등 모든 압축 확장자 윈도우 등록
  - **제어판 "프로그램 추가/제거 (앱 및 기능)"에 정식 등록** (언인스톨 지원)
